Welcome to the new Kani website! What started as a blog is growing into the place to learn what is happening around [Kani](https://github.com/model-checking/kani): news, projects, research, and how to reach us. Every existing post is still here, at the same URL.

## Where things live

We want it to be obvious where to go, so each place has one job:

- **[The Kani Book](https://model-checking.github.io/kani/)** teaches you how to use and develop Kani: installation, tutorials, reference, and contributor docs. If it teaches Kani, it belongs in the Book.
- **This website** explains the Kani project and what is going on around it.
- **[GitHub](https://github.com/model-checking/kani)** is where the work happens: issues, pull requests, and milestones.
- **Zulip** is where we talk: questions, design ideas, research, and collaboration.

## What's on the site

- **[Blog]({{ "/blog/" | relative_url }})**: long-form posts like this one. Releases, case studies, feature deep dives, and project results.
- **[Projects]({{ "/projects/" | relative_url }})**: the big public initiatives, each explaining the why and the what. The day-to-day work stays on GitHub, so project pages link to it instead of copying it.
- **[Research]({{ "/research/" | relative_url }})**: papers about Kani and papers that use it.
- **[Contact]({{ "/contact/" | relative_url }})**: Zulip for conversation, GitHub for tracked work.
- **[Documentation](https://model-checking.github.io/kani/)**: straight to the Kani Book.

## Get involved with a project

The first project on the site is [AutoHarness]({{ "/projects/autoharness/" | relative_url }}), which generates proof harnesses for you. Read the page, try it on your crate, and jump into its [GitHub milestone](https://github.com/model-checking/kani/milestone/33).

Have an idea for an initiative the Kani community should know about? [Open an issue in the website repository](https://github.com/model-checking/kani-verifier-blog/issues) and propose a new project page. Pages are plain Markdown, so a pull request works too.

Happy verifying!
