## Zulip

Use Zulip for questions, technical and design discussion, research conversations, and collaboration.
Start a topic about Kani in the [wg-formal-methods channel](https://rust-lang.zulipchat.com/#narrow/channel/183875-wg-formal-methods) of the Rust project Zulip.

## GitHub

Use [GitHub issues](https://github.com/model-checking/kani/issues) for bug reports, feature requests,
and tracked engineering work. For open-ended questions, [GitHub Discussions](https://github.com/model-checking/kani/discussions) is also available.

## Security

To report a security issue, follow the [security policy](https://github.com/model-checking/kani/security/policy). Do not open a public issue.
